# Muqadsa Qudoos — Portfolio

Personal portfolio site for Muqadsa Qudoos, a Data Science graduate (PUCIT) focused on data analysis, business analytics, and machine learning.

**Live site:** [muqadsaqudoos.github.io](https://muqadsaqudoos.github.io)

## About

A single-page portfolio covering education, work experience, projects, leadership roles, skills, and achievements — built as one self-contained HTML file with no build step or external dependencies beyond Google Fonts.

## Sections

- **Intro** — name, focus areas, contact CTA
- **About** — background and quick stats (degree, CGPA, focus, location)
- **Experience** — Software Engineering Internship at Spacebar Technologies, plus TA roles
- **Projects** — Basarat (AI assistive app, FYP), YouTube Like Ratio Predictor, Spotify Track Popularity Prediction, Decoding the Zodiac, Emigration Trends in Pakistan
- **Leadership** — Vice President (Event Management Society), Outdoor Head (Sports Society), Group Leader (FYP)
- **Skills** — languages, data & analysis tools, workflow
- **Achievements** — competition placements and certificates
- **Contact** — email, phone, LinkedIn, GitHub

## Built with

- HTML5 / CSS3 (no framework)
- Vanilla JavaScript (scroll-based nav highlighting)
- Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [Inter](https://fonts.google.com/specimen/Inter), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)

## Running locally

No build tools required. Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/muqadsaqudoos/muqadsaqudoos.github.io.git
cd muqadsaqudoos.github.io
open index.html
```

## Deployment

Hosted for free via GitHub Pages from this repository's `main` branch. Any push to `main` updates the live site.
